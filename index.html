Take it offline

The terminal program reads the same data file as this site. Download it once, copy it with a flash drive to any computer, and it works with no signal.

Download the C program Download the data file

  1. Download both files and keep them in one folder.
  2. Compile the program (Dev-C++ works) and run it.
  3. Choose search, compare or export from the menu.
  4. When internet is available, it checks for a newer data file by itself.

Help keep it accurate

Anyone can suggest a correction. Every change goes through a pull request that other volunteers review, so nobody can quietly edit a record.
